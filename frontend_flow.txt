# Frontend Flow Document

# Academic Burnout Prediction & Monitoring Platform

Version 1.0

---

# 1. Project Overview

The Academic Burnout Prediction & Monitoring Platform helps students identify, monitor, and prevent academic burnout through assessments, mood tracking, analytics, AI-powered wellness support, and personalized recommendations.

This document defines the complete frontend structure, user flow, page hierarchy, navigation, layouts, UI components, button placements, and route behavior.

---

# 2. User Journey

## New User Flow

Landing Page
→ Register/Login
→ Email OTP Verification
→ Home Page
→ Initial Assessment (Mandatory)
→ Assessment Success
→ Dashboard Access

## Existing User Flow

→ Home Page
→ Dashboard
→ Journal
→ Recommendations
→ History & Trends

# 16. Route Protection Rules

Public Routes:

/
/auth/register
/auth/login
/auth/verify-otp
/auth/forgot-password

---

Authenticated Routes:

/journal
/profile
/notifications

---

Assessment Protected Routes:

/dashboard
/dashboard/history
/dashboard/recommendations

Condition:

assessmentCompleted = true

Else:

Redirect → /assessment
