BURNOUT GUARD PROJECT DOCUMENTATION

================================================================================
1. PROJECT OVERVIEW
================================================================================
Burnout Guard is a comprehensive wellness tracking platform that helps students monitor and manage their burnout risk through:
- Daily/weekly assessments
- AI-powered journaling with sentiment analysis
- Personalized wellness recommendations
- Real-time burnout risk tracking
- Admin dashboard for overseeing student wellness
- Chrome extension for quick access

3.1 Authentication & User Management
================================================================================

Features:

- Login with email/password

- Token-based session management (JWT)

Implementation Details:

- Models: `Student.ts`, `Admin.ts`
- Endpoints (`auth.routes.ts`):
  - POST `/api/auth/register` → Register new user

  - POST `/api/auth/reset-password` → Reset password with OTP

  - PATCH `/api/auth/me` → Update user profile

Frontend:
- State management in `useStore.ts` with `login()`, `register()`, `verifyOtp()`, `logout()` actions

Extension:

4. SESSION MANAGEMENT
================================================================================

Session Timers:
- Access Token (JWT): 2 days expiry
- Refresh Token: 7 days expiry
- Frontend localStorage session duration: Also 2 days

Files Involved:
- Backend: `token.service.ts`, `auth.service.ts`
- Frontend: `useStore.ts` (storeSession(), clearSession(), getStoredAuthToken())
- Extension: Uses local storage with no fixed expiry (token kept until logout)

Flow:
1. User logs in → receives JWT token + refresh token
2. JWT stored in frontend localStorage
3. Before API requests, frontend checks if token is expired
4. If expired, frontend attempts to refresh using refresh token
5. If refresh fails, user is logged out

8. CHROME EXTENSION DETAILED IMPLEMENTATION
================================================================================

8.1 Extension Overview
The Burnout Guard Chrome extension provides quick, at-a-glance access to wellness data and daily reminders without needing to open the full web app.

8.2 Extension Architecture (Manifest V3)
Files:
- manifest.json: Core configuration
- background.js: Service worker (persistent logic)
- popup.html: Popup UI
- popup.js: Popup interactivity
- contentScript.js: Frontend web integration
- icons/: Extension icons in multiple sizes

8.3 manifest.json Configuration
Permissions declared:
- "storage": For storing user token and reminder preferences
- "alarms": For scheduling daily reminders
- "notifications": For displaying system notifications
- Host permissions for: localhost:5173 and burnout-project-xbf1.vercel.app

Configuration details:
- Manifest version: 3 (modern Chrome extensions standard)
- Default popup: popup.html
- Background service worker: background.js
- Content script: Injected into frontend web pages for integration
- Icons: Provided in 16x16, 48x48, 128x128 sizes

8.4 background.js Implementation
Responsibilities:
- Scheduled reminder alarms
- Displaying system notifications
- Message passing with popup

Core functionality:
1. createNotification(title, message): Helper to create Chrome notifications with extension icon
2. Alarm listener: Triggers when reminder alarm goes off, shows notification
3. Message listener: Handles 3 types of messages from popup:
   a. "SET_REMINDER": Saves reminder time, creates Chrome alarm
   b. "GET_REMINDER": Retrieves saved reminder time from storage
   c. "CLEAR_REMINDER": Cancels alarm and clears saved time
4. Initialization: On extension startup, checks for existing saved reminder and re-creates alarm if needed

Alarm implementation details:
- Uses chrome.alarms.create(name, { when, periodInMinutes })
- Time is converted from HH:MM format to a timestamp
- If reminder time is already past today, schedules for tomorrow
- Repeats every 24*60 minutes (daily)

8.5 popup.html Implementation
UI Components:
- Loading state (dots animation)
- Login prompt (token input + website link)
- User dashboard (when logged in):
  - Header with user greeting
  - Burnout risk card (score + risk level)
  - Stats section (just streak, no mood score anymore)
  - NEW: Daily Reminder section (toggle + time picker + save button)
  - Quote display
  - Buttons: Open Dashboard, Log Out

Styling details:
- Dark theme with gradient background
- Responsive width
- Custom styles for reminder toggle (switch UI)
- Gradient accent colors (purple/blue theme)

8.6 popup.js Implementation
Responsibilities:
- User authentication (token input, storage, API calls)
- Fetching user data (profile, burnout risk, streak)
- Reminder UI logic
- Communicating with background script

Key functions:
1. loadUserData(): Fetches and renders user data
2. getReminderTime(), setReminderTime(), clearReminder(): Wrap chrome.runtime.sendMessage calls to communicate with background
3. renderApp(user, burnout, streakData, quote): Renders dashboard UI including reminder section
4. initReminderUI(): Loads existing reminder state, sets up toggle and save handlers

Reminder UI flow:
- User toggles "Daily Reminder" on
- Time input appears, defaulted to 21:00 (9 PM)
- User selects desired time
- User clicks "Save"
- popup.js sends "SET_REMINDER" message to background
- background.js creates alarm and saves time
- Status message shows "Reminder set for [time]"
- When toggled off: sends "CLEAR_REMINDER" to cancel alarm

8.7 contentScript.js Implementation
- Injected into Burnout Guard web pages
- Handles communication between frontend and extension
- Can pass token from frontend to extension automatically (optional feature)

8.8 Extension Token Flow
1. User logs into web app
2. User copies token from web app
3. User pastes token into extension popup
4. Token stored in chrome.storage.local
5. Extension uses token for all API requests
6. Token persists across browser restarts
7. User can log out to clear token

8.9 Packaging the Extension
- All extension files are in /extension folder
- Compress folder into ZIP for distribution
- Updated ZIP available in /frontend/public/burnout-guard-extension.zip for web download
- Users can install unpacked (developer mode) or from ZIP
