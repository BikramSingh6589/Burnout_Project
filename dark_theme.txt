# Dark Theme Design System Specification

# Academic Burnout Prediction Platform

Version: 1.0

---

# 1. Dark Theme Philosophy

The dark theme should feel:

* Calm
* Focused
* Comfortable
* Professional
* Wellness-Oriented
* Eye-Friendly

The goal is to reduce eye strain during long study sessions and late-night usage.

Avoid:

* Pure Black (#000000)
* Neon Colors
* High Contrast Everywhere
* Aggressive Red Alerts
* Gaming-style UI

---

# 2. Dark Theme Style

Theme Name:

Midnight Wellness

Design Inspiration:

* Linear Dark

# 6. Design Tokens

IMPORTANT

Never hardcode colors.

Use CSS Variables only.

---

:root.dark {

--color-primary: #4F46E5;

--color-secondary: #2DD4BF;

--color-success: #22C55E;

--color-warning: #FBBF24;

--color-danger: #F87171;

--color-background: #0F172A;

--color-background-secondary: #111827;

--color-surface: #1E293B;

--color-surface-elevated: #334155;

--color-border: #334155;

--text-primary: #F8FAFC;

--text-secondary: #CBD5E1;

--text-muted: #94A3B8;

--text-disabled: #64748B;

}

Changing:

--color-primary

must update the entire dark theme.

# 18. Theme Switching Rules

The application must support:

* Light Theme
* Dark Theme

Theme switching should occur by toggling:

html.dark

or

data-theme="dark"

No component should require manual color changes.

All components must automatically adapt through CSS variables.
